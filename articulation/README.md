# Articulation

AI communication training application.

This project is currently being developed on the `articulation-mvp` branch of the repository.

## Scope

The MVP is Android-first and designed to support iOS later. It focuses on realistic, photorealistic AI conversation characters, adaptive communication training, vocabulary development, coaching, and replay.

## Architecture direction

- Cross-platform mobile client
- Modular backend
- Provider abstractions for LLM, STT, TTS, and avatar services
- Local/private AI support as a first-class architecture concern
- Jetson-based development and AI infrastructure

Product and technical specifications will be added under `articulation/docs/`.
